# Christmas at Ours

Shared planner for Christmas 2026 (24 to 28 December): RSVPs, menu by day, meal polls and a shopping list for the Tesco order.

- `index.html` is the page, served by GitHub Pages.
- `apps-script/Code.gs` is the Google Sheet backend. Paste it into the Sheet's Apps Script editor, set the two codes, run `setup`, deploy as a web app, then put the web app URL in `API_URL` at the top of the script in `index.html`.
